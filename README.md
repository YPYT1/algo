# algo

算法练习仓库（TypeScript + Bun）。

## 环境

- [Bun](https://bun.sh) >= 1.4

```bash
bun install
bun run dev
```

也可直接：

```bash
bun src/main.ts
```

## 脚本

| 命令 | 说明 |
|------|------|
| `bun run dev` | 运行 `src/main.ts` |
| `bun run start` | 同上 |
| `bun run build` | 打包到 `dist/` |
| `bun run typecheck` | 仅做类型检查 |
